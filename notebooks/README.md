# Notebooks

This folder contains the main Jupyter notebook for the project:

* **Spotify_MoodBased_Recommendations.ipynb** – Implements the full machine learning pipeline, including data preprocessing, mood labeling, model training, evaluation, and the recommendation system.

## How to Run

I recommend using Google Colab, as it is the environment I used to create the notebook. However, Jupyter Notebook also works.

To run the project:

1. Open the notebook
2. Load the dataset (via upload or GitHub link)
3. Run all cells sequentially

## Contents

The notebook includes:

* Data loading and exploration
* Feature selection and preprocessing
* Mood classification using machine learning models
* Model evaluation (accuracy, precision, F1-score, confusion matrix)
* Mood-based music recommendation system
