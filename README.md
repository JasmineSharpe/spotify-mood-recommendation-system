# Mood-Based Music Recommender

A machine learning-based system that classifies songs by mood using Spotify audio features and recommends music based on user-selected emotions.

## Project Goals
- Preprocess Spotify audio feature data
- Create mood labels
- Train classification models
- Compare model performance
- Recommend songs based on mood

## Models
- Logistic Regression
- Decision Tree
