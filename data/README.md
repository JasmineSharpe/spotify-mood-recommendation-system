# Dataset

This project uses a Spotify dataset containing various audio features for songs, such as danceability, energy, valence, tempo, and more.

## Source

The dataset was obtained from Kaggle from User @MAHARSHIPANDYA:

(https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset?resource=download)

## Description

The dataset includes:

* Track information (name, artist, genre)
* Audio features (danceability, energy, valence, acousticness, etc.)
* Popularity and duration metrics

These features are used to classify songs into mood categories and build a recommendation system.
